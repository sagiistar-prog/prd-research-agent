# 验收边界

当前技术证据见 [0.3 版验收记录](evidence-review-acceptance.md)。旧版审计保留为历史，不是当前功能依据。

自动化检查输入契约、引用原文、输入变更失效、依赖图、约束响应、指标状态、导出一致性、浏览器交互和部分可访问性规则。它不验证需求真实性、优先级是否最优、引用是否真的支持推论、行业法规、客户收益或方案中业务产品的实现。

独立技能试跑使用虚构汽车售后自然段需求，执行宿主规划再运行验证器；两个示例不代表任意行业泛化保证。没有真实用户参与和生产部署验收。

页面没有远程服务、账号、数据库、外部加载或分析上报。`docs/metrics.schema.json` 是未来测量的最少事件契约，当前页面不发送事件。任何真实用户研究需事先定义任务和数据使用范围。
